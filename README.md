## 🔭 Visão Geral

Terminal Vue.js é uma plataforma educacional projetada para ajudar no aprendizado dos conceitos fundamentais e avançados do Vue.js. Com uma interface única inspirada em terminais de computador e estética hacker, o projeto fornece exemplos interativos e exercícios práticos que cobrem desde interpolação básica até comunicação entre componentes.

A aplicação é dividida em duas seções principais:
- **MÓDULOS DE EXEMPLOS**: Demonstrações interativas de recursos do Vue.js
- **MÓDULOS DE EXERCÍCIOS**: Desafios práticos para aplicar os conhecimentos adquiridos

## 🖥️ Interface Terminal

A interface foi cuidadosamente projetada para simular um ambiente de terminal hacker, com:

- **Cursor personalizado** que segue o movimento do mouse
- **Efeitos de scanline** e textura de tela CRT
- **Animações de glitch** em elementos de texto
- **Códigos binários** que aparecem aleatoriamente durante a navegação
- **Simulação de sistema** com medição de tempo de atividade e uso de memória

Esta abordagem de design não apenas proporciona uma experiência visual única, mas também reforça a natureza técnica do aprendizado de programação.

## 📚 Exemplos Disponíveis

A plataforma inclui exemplos interativos que demonstram conceitos-chave do Vue.js:

1. **Interpolação Básica**: Exibição de variáveis e expressões
2. **Renderização Condicional**: Uso das diretivas v-if, v-else-if e v-else
3. **Renderização de Listas**: Uso da diretiva v-for para trabalhar com arrays
4. **Diretiva HTML**: Renderização segura de HTML dinâmico
5. **Two-Way Binding**: Uso da diretiva v-model para binding bidirecional
6. **Classes Dinâmicas**: Aplicação de classes CSS condicionais
7. **Estilo Dinâmico**: Manipulação de estilos inline
8. **Eventos de Teclado**: Captura e manipulação de eventos de teclado
9. **Props**: Comunicação entre componentes pai e filho
10. **Eventos Personalizados**: Emissão e captura de eventos entre componentes

Cada exemplo é interativo, permitindo que você veja o código em ação e entenda como ele funciona.

## 🏋️ Exercícios Práticos

Os exercícios proporcionam oportunidades para aplicar os conceitos aprendidos:

1. **Exercícios de Interpolação**: Praticar exibição de dados
2. **Exercícios Condicionais**: Implementar lógica de renderização condicional
3. **Exercícios de Listas**: Trabalhar com arrays e objetos
4. **Outros Desafios**: Aplicar vários conceitos em conjunto

Cada exercício foi projetado para reforçar um ou mais conceitos importantes do Vue.js.

## 🛠️ Tecnologias Utilizadas

- **Vue.js 3**: Framework JavaScript progressivo
- **Vite**: Build tool e servidor de desenvolvimento
- **Composition API**: Abordagem moderna para organização de lógica
- **CSS Avançado**: Animações, transições e efeitos visuais
- **Dynamic Components**: Carregamento dinâmico de componentes

## 🚀 Instalação e Execução

```bash
# Clone o repositório
git clone https://github.com/jimmyadmsenior/Vue-Class-Test.git

# Entre no diretório do projeto
cd Vue-Class-Test/intro-vue

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` (ou a porta indicada no terminal) para visualizar a aplicação.
